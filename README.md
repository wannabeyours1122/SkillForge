🚀 SkillForge | Ed-Tech Landing Page
SkillForge is a high-performance, responsive landing page designed for a modern online learning platform. This project showcases the implementation of clean UI/UX principles using core frontend technologies.

🛠️ Technical Overview
Architecture: Built using semantic HTML5 for improved accessibility and SEO.

Styling: Custom CSS3 utilizing Flexbox and Grid systems for precise layout control.

Responsiveness: Mobile-first approach ensuring a seamless experience across all device sizes.

Typography: Integrated Google Fonts (Plus Jakarta Sans) for a premium, professional aesthetic.

✨ Key Features
Clean Navigation: Interactive header with smooth hover states.

Glassmorphism UI: Modern design elements with blurred background effects.

Optimized Performance: Written in pure HTML and CSS without heavy frameworks for fast loading.

Cross-Browser Compatibility: Tested and verified on Chrome, Firefox, and Safari.
